# 🌾 撒米模擬器

「撒米模擬器」是一個使用 **Matter.js** 製作的互動物理模擬網頁。
當你按住滑鼠（或觸控螢幕）時，會有米粒從指標尖端傾瀉而下，
彼此碰撞、堆疊，最終填滿整個畫面——像一場白色的療癒雨。

---

## 🎮 使用方式

開啟網頁後：

* **按住滑鼠左鍵／觸控螢幕**：開始傾倒米粒
* **按住 <kbd>Shift</kbd>**：加速傾倒
* **按下 <kbd>C</kbd>**：清空畫面重新開始
* **拖曳滑鼠／手指移動**：改變傾倒位置

米粒會根據物理重力、摩擦與彈性互動，自然地堆疊成丘。
（⚠️ 若你的電腦效能有限，請適度控制生成速度）

---

## ⚙️ 技術細節

* **物理引擎**： [Matter.js](https://brm.io/matter-js/)
* **渲染方式**： Matter.Render（Canvas 2D）
* **主要特色**：

  * 實時碰撞與重力模擬
  * 靜態牆體（地板與兩側牆）保持米粒堆疊
  * 支援滑鼠與觸控事件
  * 自動調整視窗大小

---

## 🧱 結構說明

```
index.html          # 單檔即開啟的版本
 ├─ <style>          # 內嵌樣式
 ├─ <div id="overlay"> # 操作提示文字
 ├─ <script src="matter.min.js"> # 引入 Matter.js
 └─ <script>         # 主邏輯（生成米粒、碰撞、互動）
```

核心邏輯：

* `createRice(x, y)`：生成單顆米粒（細長矩形）
* `spawnAtPointer()`：在指標附近生成多顆米粒
* `afterTick`：每次物理模擬後檢查是否傾倒中並生成新粒子
* `pruneBodies()`：自動清理掉出畫面外的粒子

---

## 🚀 執行方式

1. 將 `index.html` 儲存到本機。
2. 直接用瀏覽器開啟即可（不需伺服器）。

> 💡 若要上傳到 GitHub Pages／Vercel／Netlify，只需部署這一個檔案即可。

## 🧩 可客製化參數

| 參數                       | 預設值    | 功能         |
| ------------------------ | ------ | ---------- |
| `RICE_MIN`               | `3`    | 米粒短邊像素     |
| `RICE_MAX`               | `5`    | 米粒長邊像素     |
| `RATIO`                  | `2.2`  | 長短比例（細長度）  |
| `RICE_PER_TICK`          | `3`    | 每次生成的粒子數   |
| `RICE_PER_TICK_FAST`     | `8`    | Shift 加速模式 |
| `engine.world.gravity.y` | `1.05` | 重力加速度強度    |
